Smart extension: QR pickup point at the café counter (four IoT layers)

The student shows a one-time QR code; the counter device checks it and closes the order in the existing Firestore database.
1. Device / sensorat the café counter
Pickup point (new)ESP32-S3 microcontroller + GM65 QR scanner module, small screen, green/red LED and buzzer. About USD 30. Powered by USB.
What it readsOnly the QR code text: a random 8-character pickupCode + order ID. No camera image is stored; no name or e-mail is in the code.
Student's phone (existing)My orders shows the QR code when the order is Ready.
one scan event (~150 bytes) per pickup + a heartbeat every 60 s
2. Networkhow data travels
AITU campus Wi-Fi (2.4 GHz)The device joins a separate IoT network (VLAN) with WPA2; no access to students' devices.
HTTPS / TLS 1.2+ to Google CloudFirestore REST API, same encryption in transit as the web app (Assignment 3).
If Wi-Fi is downThe device keeps up to 200 scans in flash memory and sends them later; staff can still press Picked up on the tablet.
signed in as a device account (role device, custom claim set by the admin script)
3. Cloud / processingFirebase project “aitufood”
Firebase AuthenticationAccount pickup-point-1 with role device; the key can be revoked at any time.
Security Rules (decide)A device may only: set an order from ready to picked_up if the scanned code equals the order's pickupCode, and add a pickupScans record. It cannot read users.
Cloud Firestore (existing database)orders: + pickupCode, pickedUpAt
pickupScans (new): orderId, deviceId, result, at
devices (new): lastSeen (heartbeat)
auditLog: + action pickup_scanned
real-time listeners (onSnapshot), as for the dashboard today
4. Applicationwhat people see
Student: My ordersStatus turns Picked up at the moment of the scan; nobody has to press a button.
Café dashboard"#1154 picked up at the counter, 12:43". Device status: online / offline (no heartbeat for 3 min).
Automatic ruleIf an order is Ready and not scanned 15 minutes after its slot ends, the dashboard marks it Not collected so the kitchen can stop keeping it warm.
